# 空裂：回声 · B 版原创解谜原型

## 定位

- 源分支：`reboot-echo`，与 A 版 `art-reboot-claude` 并存。
- 独立入口：`echo.html`，不修改 A 版的漫画、地图或痴关卡。
- 类型：2D／2.5D 轻度因果解谜，参考《莱顿教授》的观察与《Ghost Trick》的物件因果，不沿用找“痴”或五毒关卡。
- 核心主题：裂痕不一定被修复，但断开的联系可以重新发生。

## 核心操作

- 拖动玉玦到物件上，或直接点击物件，执行“拨、推、拽、踩”。
- 每关只有两个关键物件、两步因果；错误顺序不推进，不惩罚、不扣血、不做背包或物品组合。
- 每关先展示断处，再通过绳结、枝条、爪印和光束立即演出结果。隐只在玩家主动询问时给提示。
- 当前关卡和步骤存 `localStorage`（`youdu-echo-journey-v1`），刷新恢复；无账号、后端或联网进度。

## 三关

1. **树拱下的铃**：把断绳拨回檐下，再拽铃。铃响后主人第一次回头。
2. **石像与种子**：把种荚拨进裂缝，再把供碗推到滴水处。新枝托起石像，游叼下穗子。
3. **两界之灯**：踩墨碟留下爪印，再拨灯对准玉玦缺口。主人看见游的剪影；裂痕仍存在，但两边终于看见彼此。

## 实现

- `app/src/echo/EchoGame.tsx`：三关状态机、玉玦拖放、点击替代操作、错误顺序反馈、提示、重开与存档。
- `app/src/echo/echo.css`：原画场景、物件墨点、有限动画、移动端布局、减少动态效果。
- `app/echo.html`：独立 HTML；`app/vite.config.ts` 只登记入口，不增加依赖。
- `qa/echo/verify.mjs`：真实 Chrome/CDP，包含错误顺序、真实拖放、刷新恢复、三关完成、结尾、重开和 375px 触摸。

最近本机验收：**35/35**，控制台错误与失败资源均为 0；`npm run build`、`npm run lint` 通过。

## 边界

- 这是用于比较的新玩法原型，不是 A 版替代品，也不代表最终方向。
- 没有新增生图或视频；没有正式配乐、其他五毒关卡、战斗、装备或复杂数值。
- Fable 只完成一次美术与体验审查，B 版设计、实现、测试和发布由 Kimi Code 完成。
