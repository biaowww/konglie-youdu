# 《空裂：游渡》美术导演与四格分镜方案（一页）

> 色值、比例均为目测，出小样前须从原画取色。渡的主人身份以主 GDD 为准；本方案不为渡另定外形，画面只用淡蓝紫点簇暗示。

## 一、原画视觉证据（必须保留）

| 来源 | 必须保留的特征 |
|---|---|
| chi-scene | 冷白纸底，大面积留白。神龛在左中，坐于横向点触叠成的石台。细树干弯成月洞形，围出一块圆形空白。右侧是竖向笔触的厚重树干，被画面裁切。蓝灰与暖灰为主，少量淡绿、杏色点缀。 |
| 概念页 | 灰、蓝灰、橄榄、赭色的竖向点触柱构成崖壁与树。石径呈 S 形上行。底部有一只极淡的点状猫。 |
| you-1 / you-2 | 实心黑团，针状毛向外放射成短划光晕。耳高而尖、间距宽。头小身长。眼是极窄的黄绿细缝，不笑、不大眼。 |
| yin | 只有正面脸，无身体、无轮廓。墨黑与中灰椭圆点自鼻心放射。黄绿楔形眼上压斜眉。Y 形鼻口是唯一连续线。点缘有湿润洇化。 |
| fen | 火焰状羽笔向外上扬，耳簇如翼张开。眼是两团黄绿光斑，无瞳、无五官。尾在左下卷成涡。颜色随情绪变，剪影不变。 |
| statue | 蓝灰底上的正面对称猫形。头部点最小最密，向外渐大渐疏。中轴一道竖墨，两侧枝状展开，底部一条横基线。多色米点（墨、灰、橄榄、杏、黄、钴蓝、紫）。它是全场唯一的对称物。 |

**通用笔法**
- 用米粒形短点，长宽约 2–3:1，半透明叠两三层得到深色，方向跟随结构。
- 纵深只靠点的疏密、透明度和大小。
- 禁用连续描边、渐变投影、轮廓光、高光、体积光、斜面、圆角卡片。
- 模糊一律做成笔触洇化，并叠纸纹，不用镜头模糊。

**GDD 有而原画未见的元素**
- 游的左耳缺口：用笔触留缺表现。
- 邮包：用几道斜向炭色背带压弯毛向。
- 玉玦：C 形环，系在包带上。
- 位面城没有原画，只用窗框、檐角、信堆表现。

## 三、痴切片：统一构图与轻量引导

**构图（表、里世界同一机位）**
- 神龛在左中，粗干在右并被裁切，月洞形圆形留白作为寻字区，留白不少于 40%。
- 游在右下，四分之三背身望向神龛，与右干的重量相抵。
- 神像用同样的笔触重画在龛口暗处，基线对齐供台。
- 灯放在龛前石阶上：几粒点作灯座，灯罩留白，两三粒杏色点作焰。

**防贴纸规则**
- 每个物体必须接触承托面。
- 边缘笔触与场景同款。
- 受同一盏灯影响。
- 至少被一处场景笔触部分遮挡。

**角色融入**
- 隐：点与右干的点同质，从树干中浮出。只有散、聚、说话三态，最多侧倾约 15°。
- 忿（蓝态）：从月洞树后探头，或以一道焰笔横掠寻字区，只短暂遮住文字。

**界面**
- 不设悬浮 HUD。计数做在玉玦弧上的刻痕，找到一个亮一格。
- 375px 下玉玦约 28px 仍需可读；读不清就放大游的取景，不另加 HUD。

**界面补充：隐的文字与探灯**

- 隐的文字:直接写在右干左侧的留白里,竖排,每行不超过 8 字,最多 3 行。不加底板、边框和气泡尾。
- 字随隐的点聚拢而逐字洇出,说完后逐粒淡散,留白恢复原状。文字不压神龛,不进入月洞寻字区。
- 探灯:光区不是亮圈,而是一片纸色略暖、纸纹更清晰的不规则区域,边缘用稀疏杏色米点收口。
- 光区内,场景点触稍稍散开,露出藏在其中的墨点「痴」字。光区外,字与周围笔触同质,不可辨。
- 灯移动时,身后留两三粒渐淡墨点,不拖光尾。

**轻量引导(至多三次,每次一行,由隐说出)**

- 为什么找:痴是浊色的一种,化成三个「痴」字藏在龛前笔触里;清掉它们,玉玦才能继续指向渡。
- 提示一(入场后,灯焰先轻跳两下):「浊色藏成了字。提灯照照看。」玩家拖动灯后即散。
- 提示二(第一个字被照出时):「看见了,就点它。」点击后,字碎成米点。
- 提示三(仅在玩家 20 秒无进展时出现):「还有,在留白深处。」
- 提示之间不连发,不暂停游戏,不设遮罩。
- 每找到一个:碎点沿弧线飞向玉玦,刻痕亮一格。
- 找齐三个:玉玦闪两拍,淡绿与杏色从神龛起逐点复色,只扩到月洞范围,其余保持灰调。忿在此刻由蓝转暖,剪影不变。

## 四、小样与验收标准(最多四张)

**小样 1:游的定型(含缺耳、邮包、玉玦)**
- 缩成纯黑剪影后,仍能认出尖耳、长身和左耳缺口。
- 全身无连续描边;背带处的毛向被压弯。
- 玉玦是唯一饱和色,缩到 28px 时 C 形与三道刻痕可数。

**小样 2:痴场景表、里对照**
- 两张叠放时,神龛、右干、月洞的位置完全重合。
- 留白不少于 40%。
- 神像是全场唯一的对称物。
- 游、灯、神像各自满足四条防贴纸规则。

**小样 3:探灯与隐的文字**
- 光区没有渐变圆和发光描边。
- 光内的「痴」字可读,光外不可辨。
- 隐的文字没有任何底板;在 375px 下字高不小于 14px,且不遮神龛。

**小样 4:第④格竖卷与开始界面**
- 五处痕迹分布在不同高度,S 形石径连续可循。
- 标题与「入山」印章落在留白处,不压任何笔触。
- 竖卷停稳的画面与开始界面背景是同一张图,没有跳切。

## 五、playable 推进顺序

每个阶段完成后都执行同一道关卡:build 通过,lint 零报错,桌面与 375px 各走查一遍并截图存档。未通过不进入下一阶段。

1. **四格①–③静帧与文字**:画幅不等的版式和翻格可用。验收:375px 下三格文字完整可读,斜切格不被裁坏。
2. **第④格竖卷与开始界面**:平移、停稳、浮出标题与「入山」。验收:点击「入山」可进入下一场景;两种宽度下印章都在拇指可及的区域。
3. **四格局部动效**:点触淡出、玉玦两拍、五字漂移。验收:动效不遮挡文字;关闭动效时画面仍然成立。
4. **痴场景静态**:表世界构图,游、灯、神像就位。验收:对照小样 2 的全部标准。
5. **探灯拖动与点字**:触屏与鼠标都可操作。验收:三个字都能被照出并点中,热区不小于 44px,刻痕逐格点亮。
6. **引导、吸收与复色**:接入隐的三次提示、忿的转色和局部复色。验收:从四格到复色可一次走通;全程提示不超过三次,没有任何卡片式 HUD。
