| `fen.webp` | `角色和关键道具/忿-反派/CATCAT24.JPG` | 后续演出候选，本版未使用 |

处理步骤：

1. 用 rclone 把只读参考副本下载到服务器工作目录。
2. 用 Pillow 转为 WebP，保留原图比例、墨点和飞白，不做写实化、高清化或重新描绘。
3. `you-cutout.png` 仅根据原图亮度生成透明通道并轻微羽化，保留毛发边缘；不重绘角色。
4. 原始概念美术只读，修改只写入新文件；生成过程无 AI 生图模型，故没有生图 prompt、seed 或图像 API 费用。

## 美术底线

- 不用蓝紫密笔海报直接承托正文；标题与操作文字必须落在可读留白或降低背景强度。
- 不用白底 sprite、现代卡片、悬浮 UI、3D 运镜或连续写实动画。
- 动效只改变绳结、枝条、爪印、光束与有限墨点；不拿整图轮播冒充演出。
- A 版另有 `a-mountain.webp` 局部微调，B 版不依赖该文件。
