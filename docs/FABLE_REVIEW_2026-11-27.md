# 《空裂：游渡》美术与体验审查

## 1. A 版最小修正

**首页**
- 去掉五个字，保留五团淡墨晕作为"山上有东西"的悬念。每通过一段路，对应的字才在墨晕里显形。
- 标题冒号单独悬在第二列下方，像掉了一笔，建议改成细间隔点或并入字距。

**五毒交代**
- 放在开场漫画末格或首次进地图时，只用一句话，例如："空裂那夜，主人心里放不下的五样东西散落山中，各成一段路。"
- 之后每到一段只显示一个字和一句猫的旁白，不要一次列全。

**猫比例**
- 现在猫约占屏高五分之一，身宽超过石径，所以像巨猫。建议缩到现尺寸的 60% 左右，坐在单块石阶上，身宽不超过 1.5 块石板，尾巴压住石阶边缘作为接地。
- 我没看到漫画第三格，只能给统一规则：全作玉玦外径固定为猫头宽的 1/3 到 1/2。
- 想突出玉玦不要放大猫，让玦的绿色成为画面里唯一的高饱和点即可。

**地图落点**
- 「灯下回望」「山腰小径」两个红点在石径外的空白处，直线连线还横穿山体。把节点坐标吸附到实际石板上，分支放在石径的拐弯处。
- 连线改成沿石径走的淡墨虚线或猫爪印。
- 节点不用圆点，改成把那块石板提亮或加深。
- 未解锁地名和左下角重复的「古树月门」一并隐藏，减少悬浮文字。

## 2. B 版：成立，但要加三条约束

"裂前改物、裂后重连"的因果是成立的。风险是两张图来回切，然后试遍所有热点。建议加这三条：

1. **先给愿望再给过去。** 每关开场先演出"现在哪里断了"（主人听不见、过不去、看不见），玩家带着明确目标去裂前。
2. **只用猫的动词。** 猫只会拨、推、叼、踩。每关可互动物不超过四个，没有背包，也不做物品组合。
3. **用玉玦当窗，不切场景。** 拖动玉玦，环内显示另一个时间，改动后的结果在同一个画面里立刻演出来。因果链要像 Ghost Trick 那样完整播放一遍。

**第一关 · 树拱下的铃**（用 chi-scene）
- 断处：主人走过亭前，听不见猫叫，铃绳烂断在地上。
1. 用玦看裂前：铃绳垂在滴水的枝下。
2. 猫把绳拨到檐下的钩子上，雨水不再淋到它。
3. 回到现在：绳子完好，猫一拽，铃响，主人第一次回头。

**第二关 · 石像与种子**（用 statue）
- 断处：石像散成一地碎点，玉玦的穗子挂在高处够不着。
1. 裂前，猫把种荚拨进石座的裂缝。
2. 猫把供碗推到檐下的滴水处，水顺着碗沿流进裂缝。
3. 现在：画面中枝条一笔一笔放射长出，托住石像。猫沿枝爬上去，叼下穗子。

**第三关 · 两界之灯**（用 you-1 和 yin）
- 断处：主人提着灯站在交界处，却望向反方向。
1. 裂前夜里，猫踩了墨碟，在灯罩纸上留下爪印。
2. 现在，猫把灯拨正，带爪印的光投向里世界。
3. 玩家转动玉玦，让缺口对准光。光穿过缺口，主人看见猫的剪影。

第三关的落点是：裂痕合不上，但两边能看见彼此。这个结尾比"修复世界"更贴合这个 IP。

## 3. 八张原画的分工与底线

| 原画 | 承担的角色 | 不能破坏的要素 |
|---|---|---|
| chi-scene | 第一关主场景，表世界的基调 | 淡、疏、大留白；不能加深描边 |
| concept-collated | 环境笔触库（树丛、石径、小猫群）；A 版地图已同源 | 竖向短笔的节奏和纸白 |
| concept-poster | 里世界或空裂瞬间的过场 | 蓝紫密笔的压迫感；不要放 UI 字 |
| fen | 情绪化身或心结的形象，只在演出时出现 | 绒毛的柔边和发光的眼睛；禁止硬抠图 |
| statue | 第二关的石像和树 | 放射状的点阵结构；不要填实 |
| yin | 里世界的"注视"，用于提示和转场 | 墨点之间的空隙和黄绿色的眼睛 |
| you-1 | 游的标准立绘、终幕剪影 | 外放的细毛笔触，这是它的气场 |
| you-2 | 近景和情感特写 | 铅笔的颗粒感和松散的边缘 |

**有限动画的做法**
- **动笔触，不动整张图。** 原画本来就是由点和短笔组成的，所以空裂可以做成笔触散开，重连做成笔触聚拢，植物生长做成逐笔出现。
- **猫只做小动作。** 眨眼、耳朵、尾尖，再加毛边 2 到 3 帧的手绘抖动，按 8 到 12 帧每秒的抽帧播放。
- **分层要少。** 最多三层视差，镜头只做慢推。
- **融进纸面。** 所有图层用正片叠底压在同一张纸纹上。禁止白边、投影、弹性缩放和匀速平移，这几样是"贴纸感"和"PPT 感"的主要来源。

## 4. 替代方向：一玦窥两界

如果测试时玩家弄不清"过去"和"现在"，就把时间轴换成同一时刻的表世界和里世界：
- 玉玦环内显示里世界，物件在那里呈现为笔触形态。
- 猫在里世界拨动一处，表世界的对应物当场变化。
- 因果是即时的，而且在同一个画面里，更适合轻度玩家。

上面三关可以原样移植，只需把"裂前"改成"里侧"。它不增加任何系统，还直接用上了已经保留的表里世界设定。建议先做第一关的两种版本，对比测试后再决定。
