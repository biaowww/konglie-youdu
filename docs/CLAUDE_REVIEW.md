# OpenRouter Claude 分镜审查与采用结果

调用：`anthropic/claude-sonnet-5.5`，仅用于审查，不直接写本地文件。

## 关键意见

- “墨点＋电影感＋非对称”只是标签堆叠，会让模型取平均化的奇幻插画，而没有说明负空间、视线路径与物理因果。
- 墨点不能只是纹理，必须说明它来自纸面撕裂、足迹、路径、袍底拖痕或聚散，否则会有滤镜和贴纸感。
- 道具词会触发悬浮图标，应直接禁止悬浮饰物，而不是要求它把悬浮物画好。
- 每格需要不同景别、密度、遮罩和局部运动，不能只把图放进网格。

## 已采用

- 漫画改为主镜头＋分镜索引，不再固定 2×2。
- 每格分别使用裂隙展开、暗部退开、足迹落下、山路揭示与墨点聚合，使用 CSS `steps()` 和遮罩。
- 末格不再讲痴的教学，改为五毒与寻找主人。
- 完成场景重新生成，不含悬浮玉玦、字母、光环或佩饰。
- 修正 caption 同时设置四边定位导致整格遮挡的问题，主镜头保留完整构图。
