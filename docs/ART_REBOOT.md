# art-reboot-kimi：独立统一美术原型

## 预览与边界

- 本地入口：`http://127.0.0.1:7106/art-reboot.html`。
- 分支：`art-reboot-kimi`。当前公开 GitHub Pages 仍为 V1，本原型没有替换公开版本。
- 流程：四格漫画 → 开始界面 → 痴表世界 → 表里切换 → 灯海与忿 → 三个痴完成 → 局部复色。
- 这是 AI 辅助美术与交互测试版，不是最终生产美术、人工清稿或完整游戏。

## 新资产

- `you.webp`：自然四肢猫，颈间挂绳与小玉玦直接绘制在角色内，无邮差包。
- `statue.webp`：由墨点聚散、飞白与排线构成的抽象猫神，不再使用写实石质雕像。
- `city.webp`、`temple.webp`：位面城与山腰古寺，使用墨点、留白和中式散点透视组织平面空间。
- `ui-*.webp`：返回、音量、提示、重置的表里两套墨点手绘图标。
- `lamp.webp`：由墨点构成的煤油灯，含提手、玻璃灯罩和火苗。
- `yin.webp`：无玉玦、抽象猫神像式的墨影引导。
- `fen.webp`：由多色墨点与动物情绪碎片组成的忿，保留受伤与防备。

旧 `03 Art` 仅作风格参考，没有继续自动抠碎点原图。候选图由既定 OpenRouter GPT Image 管线生成，脚本 `tools/prepare_art_reboot_assets.py` 只做压缩、居中、裁格与本地副本整理，不再修改原始美术。当前两批共 16 张候选图元数据记录成本合计约 $1.026，未做无节制批量生成。管线对比与选择依据见 `docs/PIPELINE_COMPARISON.md`，资产统一整理到 `03 Art/AI生成资产/`。

## 可玩实现

- `app/art-reboot.html` 与 `app/src/art-reboot/` 是独立入口，不依赖旧标题页。
- 漫画逐格揭示，格子内有角色进入、路线与场景动效；演出采用 2D／2.5D 平面分层与 `steps()` 有限动画节奏，不使用连续 3D 推拉。
- 痴保留探灯找三个目标；煤油灯可识别为幻境，忿以两次场景侵入增加灯海。
- 桌面与触屏共用同一 9:16 contain 舞台，支持减少动态效果。

## 验收

`tools/qa_art_reboot.mjs` 已验证：四格漫画、开始界面、角色与神像加载、表里切换、手绘 UI、幻境灯、忿可见、三个痴完成、375px 真实触摸、无控制台错误、无失败资源。报告与截图位于 `qa/art-reboot/`。
