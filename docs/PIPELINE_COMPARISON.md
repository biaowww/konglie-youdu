# 美术管线对比记录

## 实际使用过的管线

- **OpenRouter GPT Image**：上一版全部角色、场景、UI 均由它生成，不是 Kimi 原生绘图。
- **本地 Mac ComfyUI / Flux.1-dev Q8_0 GGUF**：本轮开始对比，使用既定 `kl_zone_concept_t2i_flux_mac_v001.json` 文生图工作流。
- 本轮没有使用 Seedance 生成静态资产，也没有引入新的模型、Key 或付费服务。

## 同题结果：抽象墨点猫神像

对比图：`03 Art/AI生成资产/comparisons/statue-pipeline-comparison.png`。

| 管线 | 结果 | 判断 |
|---|---|---|
| GPT Image，直接参考原神像与隐 | 墨点聚散、飞白、抽象猫神和冷峻感接近原画，带透明通道 | 当前适合神像、隐与抽象场景 |
| 本地 Flux，长中文 prompt | 生成现代动漫人物，偏离题材 | 淘汰，不采用 |
| 本地 Flux，简短英文 prompt | 墨点黑猫、冷峻、轮廓清晰，但偏写实且无透明底 | 可保留作游的候选，不直接替换神像 |

## 阶段结论

- 神像、隐与需要原画还原的抽象形体：优先 GPT 原图参考。
- 游需要更冷峻的候选时：保留本地 Flux 作为另一条对比路线。
- 不把“更精致”“管线更新”当作“更还原原画”的标准。
- 演出改为 2D／2.5D 平面分层与少量关键姿态，使用 `steps()`，不以连续 3D 推拉或平滑补间冒充传统动画。
